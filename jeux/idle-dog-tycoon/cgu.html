2. Description du Jeu

Idle Dog Tycoon est un jeu mobile de type idle / tycoon dans lequel le Joueur développe un élevage canin virtuel : il gère des races de chiens, combine des races pour découvrir des hybrides, améliore sa production via un laboratoire et progresse grâce à un système de prestige.

Le Jeu fonctionne principalement hors ligne. Une connexion Internet est nécessaire pour la sauvegarde cloud via Google Play Games, les succès, les achats intégrés et l'affichage de publicités.
